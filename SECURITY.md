# 🔒 Security Policy

## ✅ Supported Versions

Currently, only the main deployment of the interactive portfolio is actively supported for security updates. We highly recommend always staying on the latest `main` branch if you fork this repository.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## 🚨 Reporting a Vulnerability

Security is a top priority for this project! 🛡️ We take vulnerabilities extremely seriously and deeply appreciate the efforts of security researchers and the broader open-source community to help us keep this project safe and secure.

If you discover a security vulnerability within this project, please follow these responsible disclosure guidelines:

1. **🛑 Do NOT create a public GitHub issue.** We don't want to alert bad actors before we have a fix!
2. Instead, please send a direct email to 📧 **pandadebdatta9@gmail.com** with the subject line `[SECURITY VULNERABILITY]`.
3. 📝 Include a detailed description of the vulnerability, including step-by-step instructions to reproduce it.
4. 🧑‍💻 If possible, provide a proof-of-concept (PoC), video, or script that demonstrates the vulnerability in action.
5. 🤝 Provide your contact information so we can reach out to you if we need further details or clarification.

### ⏱️ Response Time

You can expect an acknowledgment of your report within **48 hours**. 
After initial triage, we will provide an estimated timeline for a patch. We promise to keep you informed of our progress throughout the entire remediation process! 🛠️

### 📢 Disclosure Policy

We ask that you practice responsible disclosure and allow us a reasonable amount of time (typically up to 90 days) to resolve the issue before disclosing it publicly. 

Once the vulnerability has been safely patched, we will publicly acknowledge your contribution in our release notes and `CHANGELOG.md` (unless you prefer to remain anonymous). 🏆

Thank you for helping to keep this project secure! 🙏
