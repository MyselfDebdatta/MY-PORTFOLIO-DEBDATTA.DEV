# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- GitHub Issue and Pull Request templates for streamlined collaboration.

### Changed
- **Profile Image**: Updated the hero section profile avatar to a newer high-resolution photograph.

## [1.0.0] - Initial Release

### Added
- **Cinematic Boot Sequence**: Terminal-based startup simulation.
- **Dual-Theming**: Neon Dark Mode and Clean SaaS Light Mode with intelligent transition logic.
- **Interactive UI**:
  - Global Spotlight Command Palette (Ctrl+K).
  - Ambient Music Player with UI audio visualizer.
  - Hex-grid Tech Stack Radar with detailed analytics viewer.
  - Interactive Educational Timeline Carousels.
  - Fully animated Projects Gallery.
- **Responsive Design**: Comprehensive mobile and desktop layouts utilizing Tailwind CSS.
- **Foundational Architecture**: Vite + React 18, Framer Motion for animations, and Radix UI primitives.
